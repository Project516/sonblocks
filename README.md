# son blocks

![screenshot](assets/screenshot.png)

Add the son meme into Minecraft as custom blocks!

## What does it add?

son blocks adds a variety of new blocks, from the popular [son meme](https://antifandom.com/meme/wiki/Son).

## Key Features

* New meme blocks based off of a meme
* Blocks generate as ores in the overworld

## Why would you want this?

From playing with friends, to making a meme modpack, the son blocks mod's new additions of blocks from the son memes has plenty of funny possibilities!

### Great for

* Playing a prank on a friend
* Posting on social media

## Compatibility

Currently, this mod supports NeoForge 26.1.2
